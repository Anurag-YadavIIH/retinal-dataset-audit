RetinaPrep: retinal fundus leakage audit

A curation and leakage-audit pipeline for retinal fundus datasets. Naive image-level splits leak 42% of patients across train/test on ODIR-5K; this project measures the real (modest, non-replicating) accuracy cost and catches 8 hidden duplicate-patient pairs the split can't see. Full write-up, headline numbers, and methodology are in the GitHub repository's README and WALKTHROUGH.md.
