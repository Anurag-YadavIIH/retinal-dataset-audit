RetinaPrep: leakage-audit findings

Patient overlap across split strategies

Takeaway: 1412/3358 patients (42.0%) land on both sides of image_random -- by construction, 0% do under patient_group. This is the simplest and most important chart in this project: it is a count, not a statistic, and needs no significance test.

Fellow-eye label concordance

Takeaway: Fellow eyes share the same normal/abnormal label 77.8% of the time, against a 50.5% floor from class balance alone -- real bilateral correlation, but far short of 100%. This is why the ~42% patient overlap shown above produces a modest ~0.017 AUROC effect rather than something dramatic: leaking a patient's identity leaks a noisy, ~78%-reliable hint about their label, not the label itself.

4-arm results

Takeaway: B (the correct split) scores 0.792 AUROC vs A's 0.810 -- leakage inflates the naive split, as predicted. C is +0.003 vs B (the surprising result: quality curation *cost* AUROC, sign-consistent across all 5 seeds -- see docs/notes.md for why the flattering explanation didn't survive being checked). D is -0.006 vs B, consistent with the predicted null for a curation stage removing <1% of images.

A-vs-B: does the gap replicate?

Takeaway: Run 1 (cap=4473): A-B=+0.0173, p=0.037. Run 2 (cap=4435): A-B=+0.0079, p=0.286. Run 3 (uncapped, post split-then-curate fix): A-B=+0.0183, p=0.053. Runs 1 and 3 cluster near +0.018; Run 2 sits lower at +0.008 -- none reaches significance except Run 1's uncorrected p, and none survives Bonferroni correction across the family this project holds every claim to. Three draws, one direction, no draw individually conclusive: this is what n=5 seeds being underpowered looks like when actually re-drawn twice, not argued from theory once.

Site recoverability replicates on a second dataset

Takeaway: A ResNet18 recovers which imaging site a photo came from with 84.0% accuracy on ODIR-5K and 93.2% on EyePACS, against near-identical majority-class baselines (29.3% and 29.6%) -- and both are measured AFTER normalising every image to a common 512x512, so the signal is optics/colour rendition, not pixel dimensions. Site is entangled with diagnosis in both (chi2=115.2 and 139.6). This is the check that decides whether the project's central claim generalises: EyePACS is a single US screening network, not a multi-centre aggregation like ODIR-5K, so 'site' cannot be an artifact of aggregating centres -- and the signal is STRONGER there, on a test set 5.5x larger. Caveat carried throughout: site is a resolution-derived proxy in both datasets, so it under-counts real sources wherever two cameras share a resolution.

The three-rung hierarchy: A vs B vs E

Takeaway: A (image_random, 0.810) vs B (patient_group, 0.792): +0.018 AUROC (A-B) -- real but small, and did not replicate significantly across three independent 5-seed runs (chart above). B vs E (site_group, 0.737): -0.055 AUROC (E-B) -- over 3x larger, 5/5 seeds agreeing, Bonferroni-significant (p=0.0026). Not a like-for-like comparison of test sets: E's test fold is a single held-out site with 63% abnormal prevalence vs B's 55% -- checked directly (docs/notes.md) and the drop survives prevalence-matching within 6% of its own size, so this is not a prevalence artifact. Each rung's split catches leakage the rung above it structurally cannot.

Leave-one-site-out: is E's drop one site or a real pattern?

Takeaway: 4/5 held-out sites show the same negative gap as the original arm E result (site_0) -- this is not just the one site that happened to land in the original split. site_4 is a genuine exception (+0.021, consistent across all 3 of its own seeds, not a training fluke) that class balance and embedding-distance-from-training don't explain (docs/notes.md). Every interval shown here spans zero, including site_0's -- accounting for test-fold size (not just seed variance) shows no single site's estimate is precise enough alone to rule out a true gap of zero; the sweep's value is the consistent direction across sites, not any one site's number read in isolation.

Training-set overlap falsification test

Takeaway: Removing the 43 quality-rejected images and re-splitting gives 69.2% overlap with B's original training set; removing 43 *random*, quality-uncorrelated images gives 69.4% -- statistically indistinguishable. This is the falsification test for the flattering hypothesis (curation removed informative-but-hard-to-grade images): it isn't about which images are removed, it's that StratifiedGroupKFold reshuffles ~31% of the training set from almost any small change to its input pool.

Embedding similarity: fellow eyes vs duplicates

Takeaway: Fellow-eye pairs: mean 0.934, max 0.987 (n=3034). Confirmed duplicates: mean 0.993, min 0.962 (n=11). The threshold (0.99) separates them almost completely -- 0 fellow-eye pairs sit at or above it -- but not perfectly: 1 confirmed duplicate(s) fall below it, which is exactly why dedupe.py also needs phash as an independent signal rather than relying on embeddings alone.
